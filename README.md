## Features

| Feature | Description |
|:--------|:------------|
| Write-Once Archive | Immutable storage -- files cannot be modified after save |
| 12 Categories | Code, Docs, Config, Backup, Research, Design, Media and more |
| Drag-Drop Upload | Drop files directly into categories for instant archival |
| 7-Day Rule | Items become permanently locked after 7 days |
| Catalog Search | Full-text search across all archived items and metadata |
| Version Tracking | Automatic versioning with timestamp and hash |

---

## Tech Stack

| Technology | Purpose |
|:-----------|:--------|
| HTML5 | Drag-and-drop API and file handling |
| CSS3 | DkZ Design System with red-amber theme |
| JavaScript ES6+ | Archive engine and immutability enforcement |
| IndexedDB | Client-side binary storage for archived files |
| LocalStorage | Catalog index and metadata persistence |
