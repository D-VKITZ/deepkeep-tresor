# DEEPKEEP Tresor

DEEPKEEP Tresor — Write-Once Archive, niemals loeschen.

## Features

- Immutable write-once storage for agent artifacts
- Session-based organization with YYYY-MM structure
- Automatic upload of all generated files and ZIPs
- Integration with Google Drive for cloud backup
- Thematic sorting for easy retrieval

## Tech Stack

Google Drive API · Node.js · JavaScript

## Quick Start

```bash
git clone https://github.com/D-VKITZ/deepkeep-tresor.git
cd deepkeep-tresor
npm install
# Configure Google Drive credentials
npm run upload
```
